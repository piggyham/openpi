# P4 · 双臂可恢复脚本专家与 100 次评测

> 状态：✅ 已完成
> 作用：在 P3 接触门控之上做一套**可恢复的脚本专家**——每只手给多组预抓取变体，
> 抓取被门控拒绝就后撤重试；双臂互锁；监控意外碰撞；局部耗尽则整局重置重跑。
> 最后用 100 个随机种子做正式评测，验收成功率 ≥95%。

## 1. 这一步要做什么

1. 为左右手分别设计预抓取/抓取/抬升位姿。
2. 实现右手接近→夹取→抬升→搬运→中央放置→后撤；左手同理到蓝区。
3. 双臂互锁：前一只手退出后才允许另一只手进入中央区域。
4. 不可达/碰撞/滑落/抓取失败恢复。
5. 自动记录失败阶段与原因。
6. 在随机初始条件下完成 100 次评测，成功率 ≥95%。

实现：`openarm_mission/expert.py`（`RelayScriptedExpert`，继承 `P3EpisodeRunner`）
和 `openarm_mission/p4_benchmark.py`（多进程评测 + CSV/JSON/PNG 面板）。

## 2. 专家配置：`ScriptedExpertConfig`（`config.py:149`）

- `pregrasp_height=0.50`、`retreat_height=0.52`、`closed_gripper_target=0.008`。
- `max_grasp_attempts_per_arm=3`、`max_episode_attempts=2`（局部 3 次 × 整局 2 次）。
- 预抓取 XY 偏移 `(0,0),(+4mm,0),(-4mm,0)`；Z 偏移 `(0,-4mm,+4mm)`。
- `recovery_retract_seconds=0.55`、`recovery_settle_seconds=0.25`。
- `benchmark_success_threshold=0.95`。

## 3. 抓取流程与变体选择：`_approach_and_attach`（`expert.py:204`）

对每只手，最多 `max_grasp_attempts_per_arm=3` 次：
1. 按 `(grasp_attempt-1 + episode_attempt) % N` 选 XY/Z 偏移变体（整局重试时换组）。
2. `_move_tcp` 到预抓取位（杯位 + XY 偏移，`pregrasp_height`）。
3. 重新取杯位（杯子可能被前次尝试碰动），`_move_tcp` 到抓取 TCP
   （杯位 + XY 偏移，`cup_z + physical_grasp_tcp_offset_z + Z 偏移`）。
4. `_set_gripper` 到 `closed_gripper_target`，缓慢闭合。
5. 故障注入检查：若 `--inject-right/left-grasp-failure`，抛
   `injected_{side}_grasp_rejection`（见 §6）。
6. 调 `task.try_attach(side)`（P3 接触门控）。
   - 通过：记 `grasp_succeeded`，返回当前 yaw，进入抬升。
   - 拒绝：抛 `RecoverableExpertError("contact_gate_rejected: ...")`。
7. `except (RecoverableExpertError, RuntimeError)`：若任务未结束，调
   `_recover_grasp` 后继续下一组；若任务已 `done` 则上抛。
8. 三次耗尽抛 `RuntimeError(side grasp exhausted)`。

> 关键点：抓取“是否成立”完全由 P3 接触门控决定，专家只负责“把手指摆到位、闭夹”，
> 不直接判定抓取成功——这保证指标可复现、不被脚本逻辑伪造。

## 4. 后撤恢复：`_recover_grasp`（`expert.py:162`）

记录一条恢复事件，设阶段卡“{side} 抓取恢复”，并：
1. 临时关闭碰撞检查（`_suppress_collision_check=True`，避免后撤途中误报）。
2. 张开夹爪到 `gripper_open_position`。
3. 尝试 `_move_tcp` 抬到 `retreat_height`；若 IK 失败则退回 home 关节角。
4. `_hold(recovery_settle_seconds)` 停稳。
5. `finally` 恢复碰撞检查。

## 5. 双臂互锁与碰撞监控

- **互锁**：`_run_success`（来自 `p3_episode.py`）里右手必须先 `_release_and_retreat`
  到 `WAIT_LEFT_GRASP`，左手才开始 `_approach_and_attach("left")`。状态机层面
  `WAIT_LEFT_GRASP` 也只在中央稳定 0.25 s 后才进入（见 [p3.md](p3.md) §7）。
- **碰撞监控**：`unexpected_contacts`（`expert.py:77`）遍历 `data.contact`，
  按 geom 名分类：
  - 允许：杯-桌、杯-指、同臂自接触（非跨臂）。
  - 危险：机器人-桌面、杯-机器人(非指)、左右臂互撞。
  - 危险且非允许 → 记录并抛 `RecoverableExpertError("unexpected_collision: ...")`，
    进入恢复路径。`_step_frame` 每帧调一次（任务未结束且未抑制时）。

## 6. 故障注入（`fault_injections`）

`_consume_fault(key)`（`expert.py:155`）按计数消耗一次注入。CLI 提供
`--inject-right-grasp-failure` / `--inject-left-grasp-failure`，在 `try_attach`
之前抛 `injected_{side}_grasp_rejection`，强制走后撤重试路径，用于验证恢复能力。
验收要求：双侧首次抓取拒绝注入下，同一 episode 内恢复并完成任务。

## 7. 整局重置层：`run_expert`（`expert.py:313`）

外层循环 `max_episode_attempts=2`：
1. 第 0 次直接 `_run_success()`；若失败且未 `done`，`task.fail("expert_execution_error")`。
2. 记录本次 attempt 的 `task.summary()` 与一条 `recovery_action`（`reset_episode` 或
   `terminate`）。
3. 第 1 次重置：`_reset_for_episode_attempt` → `task.reset(seed)` +
   `controller.reset_targets()`，重跑。
4. 成功则 break。

最终 `summary` 合并：`expert_success`、`episode_attempts`、每只手 `grasp_attempts`、
`recovery_count`（排除成功类事件）、`collision_count`、`final_xy_error_m`、
`recovery_events`、`collision_events`、`attempt_summaries`、`frames`、`video`。

## 8. 100 次评测：`p4_benchmark.py`

- `run_benchmark(episodes, workers)`（`p4_benchmark.py:381`）用
  `multiprocessing.get_context("spawn")` + `ProcessPoolExecutor` 并行跑种子
  0~episodes-1，每进程在独立 scratch 目录跑 `RelayScriptedExpert(seed)`。
- `_evaluate_seed` 返回每条 `{seed, success, attempts, recoveries, collisions,
  final_xy_error_m, final_upright_angle_deg, failure_reason, ...}`，失败也保留。
- `_aggregate`（`p4_benchmark.py:100`）：成功率、阈值比较、终点 XY 误差
  mean/P95/max、最终倾角 mean/max、恢复次数、碰撞次数。
- 输出：逐 episode CSV（`_write_csv`，含 `final_xy_error_m` 等列）、完整 JSON、
  PNG 可视化面板（`_write_dashboard`，画成功率条 + 阈值线 + 终点误差分布 + 恢复/碰撞统计）。

```bash
.venv/bin/python -m openarm_mission.p4_benchmark --episodes 100 --workers 4
```
产物：`artifacts/p4/p4_benchmark_100.{csv,json,png}`。

## 10. 验收结果（SPEC §11）

- 固定种子 0~99，随机化 XY/yaw/质量/摩擦，共 100 次。
- 验收线 ≥95%；**实测 100/100，成功率 100%**。
- 100 次中自动后撤重试 5 次、意外碰撞 0 次、整局失败 0 次。
- 平均终点 XY 误差 `9.667 mm`，P95 `10.391 mm`，最大 `10.476 mm`。
- 平均最终倾角 `0.017747°`，最大 `0.034407°`。
- 双侧首次抓取拒绝故障注入实测恢复 2 次，左右手均在第 2 次尝试成功并完成蓝区稳定放置。
