# P2 · 双臂控制器、安全限制与动态展示

> 状态：✅ 已完成
> 作用：在 P1 的模型之上实现“14 维笛卡尔动作 → 关节力矩”的完整安全控制管线，
> 并用一条**确定性脚本轨迹 + 显式抓取锁存**把整段接力跑通、导出视频。这是
> 控制基础设施的演示，不是物理抓取策略（物理抓取在 P3）。

## 1. 这一步要做什么

1. 解析左右臂关节、DOF、actuator、TCP。
2. 实现 14 维双臂同步动作入口。
3. 实现平移/旋转/工作空间限幅。
4. 实现阻尼最小二乘全位姿 IK + 仅位置 IK。
5. 实现关节限位、关节目标步长限制、超速制动。
6. 实现重力补偿关节 PD、力矩裁剪、夹爪归一化命令映射。
7. 加模型/非法动作/IK/物理步进测试 + 命令行 smoke test。
8. 实现右手 A 取杯→中央放置、左手中央取杯→蓝区放置的分阶段轨迹。
9. 加入确定性纸杯抓取锁存（保证展示可重复）。
10. 导出 MP4、GIF、三阶段故事板、JSON 成功摘要。

控制代码在 `openarm_mission/controller.py`，展示在 `openarm_mission/demo.py`，
基础运动原语（`_move_tcp/_move_joints/_set_gripper/_hold`）在
`openarm_mission/p3_episode.py` 的 `P3EpisodeRunner`（P4/P5 复用同一套原语）。

## 2. 控制器总览：`BimanualCartesianController`

`controller.py:61`，固定 14 维（`ACTION_DIMENSION = 14`）。它持有四个目标字典：
末端位置 `target_position`、姿态 `target_quaternion`、关节角 `target_joint_qpos`、
夹爪 `target_gripper`，初始由 `reset_targets()` 同步到当前仿真状态。

### 2.1 动作校验 `_validate_action`（`controller.py:99`）
- 形状必须 `(14,)`，否则 `InvalidActionError`。
- 必须全有限（无 NaN/Inf）。这是 P0“拒绝错误维度/NaN/Inf”的落地。

### 2.2 目标积分 `_integrate_target`（`controller.py:107`）
对每只手的 7 维子动作：
- 平移 `[:3]` 先 `clip` 到 `±max_translation_delta`（0.025 m）。
- 旋转 `[3:6]` 用旋转向量，若范数 > `max_rotation_delta`（0.12 rad）则**等比缩放**
  （保方向、限幅）。
- 目标位置 += 平移，再 `clip` 到工作空间 `[workspace_min, workspace_max]`
  （`x∈[0.18,0.82], y∈[-0.46,0.46], z∈[0.30,0.78]`）。
- 姿态：把旋转向量增量转四元数，`mju_mulQuat` 左乘到当前目标四元数，归一化。
- 夹爪 `[6]` `clip` 到 `[-1,1]`，再用 `interpolation=0.5*(cmd+1)` 在
  `gripper_open_position=0.044` 与 `gripper_closed_position=0` 间插值（-1 全开、+1 全闭）。

> 平移/旋转/夹爪三类限幅都在这一步完成——P0 安全约束的核心实现点。

### 2.3 同步执行 `apply_action`（`controller.py:135`）
1. 校验动作。
2. 把 14 维切成 `left=action[:7]`、`right=action[7:]`，**两臂先各自积分目标**
   （同一帧同时更新，满足“双臂同步”）。
3. 对 left、right 依次 `solve_ik` 得到目标关节角。
4. `joint_delta = result.qpos - current`，再 `clip` 到
   `±max_joint_target_delta`（0.20 rad）→ 单步关节变化限幅。
5. 写入 `target_joint_qpos`，返回 `IKResult`。

### 2.4 阻尼最小二乘 IK：`solve_ik`（`controller.py:172`）

输入：`side`、`target_position(3,)`、`target_quaternion(4,)|None`。传 `None` 即
**仅位置 IK**（手腕姿态自由，扩大可达空间，用于跨区域长轨迹）。

流程（`controller.py:200-265`）：
- 复制一份 `ik_data`，冻结另一臂状态、`qvel=0`，只动当前臂。
- 每轮：`mj_forward` → 取 TCP 位姿 `site_xpos/site_xmat` → 位置误差
  `target_pos - current_pos`；姿态误差用 `_rotation_error`（目标四元数与当前旋转矩阵
  的相对旋转，转成旋转向量）。
- 收敛判据：位置误差 ≤ `ik_position_tolerance=0.003`，且（仅位置模式或姿态误差 ≤
  `ik_orientation_tolerance=0.025`）。最多 `ik_iterations=100` 轮。
- 雅可比：`mj_jacSite` 取 TCP site 的位置/旋转雅可比，按 dof 索引切片。
- 求解：`delta = J^T (J J^T + λ²I)^{-1} e`，λ=`ik_damping=0.035`（DLS 正则项，
  小雅可比奇异时稳定），步长 `ik_step_size=0.65`，单步再限到
  `ik_max_joint_step=0.10`。
- 关节限位：`clip` 到 `jnt_range ± joint_limit_margin=0.015`（保留边界余量）。

返回 `IKResult(qpos, position_error, orientation_error, converged, iterations)`。

> 注：IK 在一个**独立 `MjData`** 上迭代，不污染真实仿真状态；真实仿真由 `compute_ctrl` 用 PD 推进。

### 2.5 力矩 PD：`compute_ctrl`（`controller.py:271`）
对每只手：
- `error = target_joint_qpos - qpos`，用 `arctan2(sin,cos)` 包角（处理 ±π 翻转）。
- `torque = Kp*error - Kd*qvel + qfrc_bias`（**重力补偿**：加 `qfrc_bias` 让 PD
  只补误差项，不背重力）。
- 超速制动：若 `|qvel| > max_joint_velocity`，对应项改为
  `qfrc_bias - brake_gain*qvel`（强阻尼制动）。
- 力矩 `clip` 到官方 `actuator_forcerange`（`_torque_limits`）。
- 夹爪写位置目标到 `ctrl[finger_actuator_ids]`。
- 末尾断言 `ctrl` 全有限，否则 `RuntimeError`。

增益（`config.py:104-107`）：`Kp=(120,120,85,75,30,30,30)`、
`Kd=(2.7,2.7,2.2,2.2,1.5,1.5,1.5)`、`max_joint_velocity=(2.5,2.5,2.5,2.5,3,3,3)`，
越靠近末端增益越小，符合远端大惯量、末端低惯量的分布。

### 2.6 步进 `step(substeps=1)`（`controller.py:314`）
每个子步：`compute_ctrl()` 写 `ctrl`，`mj_step` 推进物理。`timestep=0.002`，
`runner_fps=20` 时每帧 25 个子步。

### 2.7 P4.5 用到的力控接口
- `set_gripper_force_limit(side, force_n)`（`controller.py:297`）：改
  `actuator_forcerange` 为 `±force_n`，实现 8~12 N 随机力上限的位置阻抗。
- `gripper_actuator_forces(side)`（`controller.py:307`）：读双指实际力，用于
  P4.5 抓取确认（≥0.8 N）。

## 3. 动态展示：`RelayDemo`（`demo.py`）

### 3.1 确定性抓取锁存（关键边界）
P2 的纸杯**不是物理抓取**。`RelayDemo._disable_scripted_cup_contacts` 关掉纸杯
与桌面的脚本接触，`_sync_cup`（`demo.py:137`）每帧把纸杯 free-joint 位姿写成
“跟随当前 TCP 的直立姿态”；`_attach(side)` 激活跟随，`_release_at(xy)` 把杯子
锚定到中央或蓝区并退出跟随。这样做是为了在跨 MuJoCo 版本里稳定复现展示，
**不可当作物理抓取指标**（SPEC §7 明确声明）。

### 3.2 分阶段轨迹（`run`，`demo.py:481`）
- 右手：到 A 区上方预抓取 → 下降 → 闭合夹爪 → `_attach("right")` → 抬升 →
  搬到中央上方 → 下降 → `_release_at(center)` → 后撤回 home。
- 左手：等中央稳定 → 到中央上方 → 下降 → 闭合 → `_attach("left")` → 抬升 →
  搬到蓝区上方 → 下降 → `_release_at(blue)` → 后撤。
- 跨区域长位移用 `_solve_position`（仅位置 IK，`demo.py:174`），让手腕姿态自适应。

### 3.3 视频与导出
- `mujoco.Renderer` 渲染主视角；`imageio.get_writer` 写 MP4（`demo.py:103`）。
- `_overlay` 在画面上叠中文阶段卡、路线节点、颜色编码进度条、总进度。
- `_emit_frame` 推帧；`_phase` 推进阶段并在关键点抓 `storyboard` 帧。
- `_write_outputs`（`demo.py:437`）写 JSON 成功摘要；`_write_storyboard` 拼三阶段
  静态图。
- 默认产物：`artifacts/openarm_paper_cup_relay.{mp4,gif,json}` + `_storyboard.png`。
