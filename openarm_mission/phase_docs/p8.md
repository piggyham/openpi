## 4. sim2real 标定：双相机/手眼

仿真里桌面、TCP、相机外参都是已知常量；真机上必须标定：

- **桌面/工作台标定**：实测真机桌面上表面高度，对齐 P4.5 用的 `table_top_z`
  （P4.5 已把桌面抬到 0.33 m 作为工作台高度标定的先例，见 [p4_5.md](p4_5.md) §2）。
- **手眼标定（eye-to-hand / eye-in-hand）**：
  - 前视相机（`mission_front_camera`）→ 真机外部相机的外参。
  - 双腕相机（`mission_{side}_wrist_camera`）→ 真机腕载相机相对 TCP 的外参。
  用标定板求 `camera→world` / `camera→tcp` 变换，写入推理端的环境配置，使策略
  看到的图像与仿真分布对齐。
- **TCP 标定**：确认真机 TCP site 与 `mission_{side}_tcp` 定义一致（夹爪中心、
  指定朝向），影响 IK 与 action 对齐。

## 5. 真机安全保护

真机不能像仿真那样“跑飞了重来”，必须加硬件/软件保护（对应 P0 安全约束的真机版）：

- **关节限位**：`jnt_range ± joint_limit_margin`（`ControllerConfig`）映射到真机软限位。
- **速度限制**：`max_joint_velocity` + `max_joint_target_delta` → 真机最大关节速度/加速度。
- **力矩限制**：`actuator_forcerange`（手指 8~12 N）→ 真机夹爪力控上限；臂关节力矩
  上限按厂商手册。
- **双臂互锁**：把 P3 `RelayStage` 的互锁逻辑搬到真机控制器（右手未退出前左手
  不得进交接区），用状态机而非策略输出决定。
- **急停**：超速制动（`brake_gain`）的真机版 + 物理急停按钮 + 非有限状态立即停。

## 6. 域随机化（向真机泛化）

P5 已有物理/视觉随机化，P8 补真机特有的扰动维度：
- **摩擦/质量**：超出 P5 分布的杯体摩擦与质量（真机纸杯批间差异大）。
- **延迟**：推理—通信—执行链路的控制延迟（仿真里可加动作缓冲或帧延迟模拟）。
- **相机**：外参/内参/曝光扰动，模拟真机相机噪声与标定残差。
- **桌面高度微扰**：±几 mm，模拟真机桌面与标定的不确定性。
