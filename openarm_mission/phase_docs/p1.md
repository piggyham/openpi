# P1 · 导入 OpenArm v1 模型与任务场景

> 状态：✅ 已完成
> 作用：把官方 OpenArm v1 双臂 MJCF 装载进来，在不修改官方源文件的前提下，
> 通过 ElementTree 在内存里“包一层”组合出任务场景（桌面、三区域、纸杯、相机、
> weld），并把所有关键 MuJoCo 对象解析成可索引的 handle，供 P2/P3 直接使用。

## 1. 这一步要做什么

1. 把官方 `openarm_mujoco` 仓库固定到一个 revision，提供幂等下载脚本。
2. 加载 `v1/openarm_bimanual.xml` 并解析 mesh。
3. 给左右手 TCP 加可查询 site；统一左右夹爪为 position actuator。
4. 添加桌面、红 A 区、中央交接区、蓝 B 区。
5. 用开放顶部锥台 mesh 构造无把手纸杯；加 free joint、内壁暗面、杯口卷边。
6. 添加第三人称、俯视、双手腕相机。
7. 定义双臂 home pose 和场景 reset；离屏 framebuffer 提升到 1280×720。
8. 验证模型结构与关键命名。

实现集中在 `openarm_mission/model.py`。

## 2. 官方模型与下载

- 依赖目录：`openarm_mission/third_party/openarm_mujoco`（见 `config.py` 的
  `dependency_root`）。
- 固定 revision：`8955afb54e4adfb59a236e2b4d15192b7a02865c`。
- 幂等下载脚本：`bash openarm_mission/fetch_openarm_v1.sh`。它会在缺目录或
  revision 不匹配时重新拉取，已存在则跳过。
- 锁定信息另存于 `openarm_mission/dependencies/`。

`MissingOpenArmAssetsError` 会在文件缺失时抛出，提示运行下载脚本
（`model.py:15`、`build_mission_xml` 内 `model.py:572-575`）。

## 3. 在内存里组合场景：`build_mission_xml`

关键设计：**不写官方源文件**。`build_mission_xml(config)`（`model.py:568`）的做法是
`ET.parse(model_path).getroot()` 读入官方 XML，然后就地增删属性/挂子节点，最后
`ET.tostring` 得到自包含字符串，再 `mujoco.MjModel.from_xml_string` 编译。这样官方
仓库保持干净，版本可锁。

组装顺序（`build_mission_xml` 末段，`model.py:608-623`）：

```python
_make_grippers_position_controlled(root, config)   # 统一夹爪 actuator
_stabilize_arm_dynamics(root)                       # 反射惯量 + 阻尼
_add_tcp_sites(root)                                # TCP site + 腕相机支架
_add_task_scene(root, config)                      # 桌面/区域/纸杯/相机/weld
_add_soft_finger_pads(root, config)                 # P4.5 软指垫（默认关闭）
# 再按是否软指垫设置刚性指面 condim/friction
```

编译选项（`model.py:586-596`）：`timestep=0.002`、`gravity=0 0 -9.81`、
`integrator=implicitfast`、`cone=elliptic`、`iterations=100`、`noslip_iterations=8`、
`tolerance=1e-10`。`elliptic` 摩擦锥 + `noslip` 是为了纸杯接触稳定。视觉全局离屏
`1280×720`（`model.py:604-606`）。

## 4. 夹爪统一为位置控制：`_make_grippers_position_controlled`

官方模型左右各有两根手指 actuator `left_finger1_ctrl`/`left_finger2_ctrl` 等
（`model.py:291-292`）。这里把它们从原始类型改写为 `position` actuator
（`element.tag = "position"`），并设置：

- `kp = config.finger_servo_kp`（默认 100，P4.5 升到 240）。
- `ctrllimited=true`、`ctrlrange="0 0.044"`（0 闭合、0.044 全开）。
- `forcelimited=true`、`forcerange=±config.finger_force_limit_n`（默认 ±333 N；
  P4.5 改为随机 8~12 N，由控制器运行时改 `actuator_forcerange`）。

这样夹爪命令统一是“位置目标”，P2 控制器把归一化的 `[-1,1]` 映射成 `[0,0.044]`。

## 5. 关节动力学稳定：`_stabilize_arm_dynamics`

给 7 个关节补 `armature`（反射电机惯量）和 `damping`（`model.py:352-369`）。
数值按关节序号分档：J1/J2 `0.0081/1.0`，J3/J4 `0.1600/0.9`，J5/J6/J7
`0.0100/0.9`。目的是抑制低惯量腕关节在力矩控制下的数值振荡——这是 P0 安全约束
里“补充反射电机惯量和阻尼”的落地。

## 6. TCP site 与腕相机支架：`_add_tcp_sites`

- 在官方 `openarm_{side}_hand_tcp` body 下挂 `mission_{side}_tcp` site
  （`model.py:133-146`），位置在 TCP 原点、group 4（debug 组），控制器和任务都用
  它做末端位姿查询（`controller.solve_ik` 用 `mj_jacSite`，`task` 用 `tcp_pose`）。
- 同时在 `openarm_{side}_hand` body 下挂一个 L 形相机支架（`model.py:155-280`）：
  先沿世界向上方向走一段立柱，再沿手指前向伸出横臂，末端是相机 housing。支架有
  可视 geom（group 0，不参与碰撞）和碰撞 geom（group 3，`contype/conaffinity=1`）。
  相机 `mission_{side}_wrist_camera`，`fovy=75`。传感器相对支架向前倾斜
  `30°`，工作准备位的光轴约为“向前 30°、向下 60°”，同时观察夹爪前方和
  下方接触区域。

## 7. 任务场景：`_add_task_scene`

### 7.1 资产与材质（`_add_mission_assets`，`model.py:53-80`）
9 种材质：桌面木色、红/蓝/金区域、纸杯外表/内壁暗面、绿色指垫、相机外壳/镜头。

### 7.2 纸杯 mesh（`_paper_cup_frustum_mesh`，`model.py:83-130`）
程序化生成一个**中空、开口顶部、有限壁厚和底厚**的锥台：

- 4 个环：外底、外顶、内底（半径减壁厚、z 上移壁厚）、内顶。
- 每环 32 段顶点；外加外底中心、内底中心两个扇心点。
- 面按段拼接：外壁、内壁、顶环（杯口开放边）、外底、内底。
- 校验：`0 < wall_thickness < min(bottom_radius, top_radius)`。

这就满足了“无把手、上宽下窄的一次性纸杯”而非马克杯的要求。

### 7.3 桌面与三区域（`model.py:399-457`）
- `mission_table` body 位于 `table_center`，桌面 `mission_table_top` 为 box
  `half_size=(0.38,0.36,0.04)`，摩擦 `1.2 0.02 0.002`。
- A/B 区是 `cylinder`（半径 `region_radius=0.085`，薄盘），贴在桌面上方 3 mm，
  `contype/conaffinity=0`（不参与碰撞，只做视觉/区域判定）。
- 中央交接区 `mission_handoff_marker` 同样是金色薄盘，半径 0.07。

### 7.4 纸杯 body（`model.py:459-526`）
- `mission_cup` body 初始位置 `cup_initial_position`（A 区上方，杯底贴桌面+2 mm）。
- `freejoint`：纸杯 6-DOF 自由。
- `mission_cup_body` mesh geom：质量 `0.035`、摩擦 `1.8 0.05 0.005`、`condim=4`、
  `solref/solimp` 软接触。
- `mission_cup_inside`：内壁暗色薄圆柱，仅视觉。
- 32 段 `mission_cup_rim_*` capsule：杯口卷边，避免锋利边沿扎进指面。
- `mission_cup_center` site：绿色 debug 锚点。

### 7.5 相机（`model.py:528-548`）
- `mission_front_camera`：位于双臂头部/肩部上方 `(0.08,0,0.82)`，斜向前俯瞰
  桌面中央，`fovy=72`，覆盖红区、交接区和蓝区。
- `mission_overhead_camera`：俯视任务地图，`(0.50,0,1.25)`，`fovy=52`。
- `xyaxes` 由 `_camera_xyaxes` 计算，保证相机正对目标。

> P5 还会用到左右腕相机（这里已挂）+ 前视相机，构成“三相机”同步采集。

### 7.6 cup weld equality（`model.py:550-565`）
为 P3 预留两个 `weld`：`mission_{left/right}_cup_weld`，把
`openarm_{side}_hand_tcp` 与 `mission_cup` 焊在一起，**默认 `active=false`**，
`relpose="0 0 0 1 0 0 0"`，`torquescale=0.05`。P3 的接触门控会在运行时按需激活。

## 8. 软指垫（P4.5 专用）：`_add_soft_finger_pads`

仅当 `config.soft_finger_pads=True`（即 `FrictionMissionConfig`）时生效
（`model.py:312-349`）：把官方刚性指面 `..._finger_collision` 的
`contype/conaffinity` 置 0（关闭其碰撞），再在每个手指 body 上加一个
`mission_{side}_{finger}_finger_pad` box，`condim=6`、椭圆摩擦锥、软接触
`solref/solimp`、绿色材质、`margin=0.0005`。详见 [p4_5.md](p4_5.md)。

## 9. `OpenArmMission` 类与 handle 解析（`model.py:626`）

编译后把所有命名对象解析成索引，避免运行时反复 `name2id`：

- `arms = {"left"/"right": ArmModelHandles(...)}`（`_resolve_arm`，`model.py:668`）：
  - `joint_ids`：`openarm_{side}_joint1..7`；
  - `qpos_indices`/`dof_indices`：从 `jnt_qposadr`/`jnt_dofadr` 取出；
  - `actuator_ids`：`{side}_joint{i}_ctrl`；
  - `finger_joint_ids`/`finger_qpos_indices`/`finger_actuator_ids`：两根手指；
  - `tcp_site_id`：`mission_{side}_tcp`。
- `cup_joint_id`/`cup_qpos_address`/`cup_dof_address`：纸杯 freejoint 的 qpos/dof
  起始地址；构造时还按 `cup_linear_damping`/`cup_angular_damping` 写入纸杯
  `dof_damping`（`model.py:638-639`）。
- `cup_body_id`、`cup_geom_id`、`cup_weld_ids`、`finger_pad_geom_ids`。
- 便捷查询：`tcp_pose(side, data=None)`、`cup_position()`、`cup_quaternion()`、
  `cup_velocity()`、`save_expanded_xml(path)`。

## 10. reset（`model.py:697`）

`reset()` 把场景回到初始：`mj_resetData` → 关闭两个 weld → 双臂 `home_arm_qpos`
（`(0,0,0,0,0,0,0)`，两臂沿底座两侧自然下垂）→ 手指
`open_finger_qpos=0.044`（全开）→ 纸杯放到
`cup_initial_position`、姿态单位四元数 → 全零速度 → `mj_forward`。

P3 的 `task.reset(seed)` 在此之上再做随机化（位置/yaw/质量/摩擦）。
脚本专家开始操作某只手时，先经过桌面近边后方的净空点
`(x=0.20, z=0.52)`，再进入 `ready_arm_qpos=(0,0,0,π/2,0,0,0)`；完成任务后
沿反向路径收回，避免手腕或手指横扫桌面。另一只手始终保持自然下垂。
