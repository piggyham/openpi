## 2. 训练配置与 LoRA

基于 P6 注册的 `pi05_openarm_paper_cup_relay`（`src/openpi/training/config.py` 的
`TrainConfig`）：

- **起点 checkpoint**：用一个 π0.5 官方预训练权重做 `weight_loader`
  （`openpi/training/weight_loaders.py`）。π0.5 已有通用操作能力，从它出发比从零训
  快得多、数据需求小。
- **LoRA**：用 `src/openpi/models/lora.py` 给注意力/MLP 投影插入低秩适配器，
  `freeze_filter` 冻结原参数、`trainable_filter` 只放开 LoRA 注入参数
  （`TrainConfig.freeze_filter`/`trainable_filter`，`config.py:492-498`）。好处：
  显存与时间可控，且不破坏预训练能力。
- **数据**：P5 的 `local/openarm_paper_cup_relay`（200 episodes/86,400 frames，
  160/20/20）。`data_loader.py` 按 batch 拉取，`OpenArmInputs` 打包。
- **超参**（建议起点）：`batch_size` 按显存定，`num_train_steps≈20k~30k`，
  `save_interval=1000`，`keep_period=5000`，`lr_schedule=CosineDecay`，
  `optimizer=AdamW`，`ema_decay=0.99`，`pytorch_training_precision="bfloat16"`，
  `fsdp_devices` 按卡数。`wandb_enabled=True` 记 loss/action 误差。
- **训练命令**（openpi 既有 CLI 风格）：
  ```bash
  .venv/bin/python -m openpi.training.train_config \
    --config pi05_openarm_paper_cup_relay --exp-name lora_v1 \
    --overwrite   # 或 --resume 续训
  ```

## 3. 每 1k steps 保存并评测

- `save_interval=1000` 会按步存 checkpoint 到
  `checkpoints/pi05_openarm_paper_cup_relay/lora_v1/{step}/`，并带 `assets/norm_stats`。
- 评测脚本（建议新建 `openarm_mission/p7_eval.py`，复用 `p45_benchmark.py` 的多进程
  框架）每个 checkpoint 跑 N 个种子，闭环评测而非开环回放：
  - 起 `serve_policy.py --env openarm` 推理服务（或进程内 `create_trained_policy`）。
  - 每个 episode：`task.reset(seed)` → 每帧把 state+三相机图+prompt 发给 policy →
    收 14 维 action chunk → `controller.apply_action` → `task.update` 推进状态机。
  - 收集 `task.success`、`failure_reason`、各阶段耗时、终点误差、倾角。

## 4. 至少 100 个 episode 的分阶段失败统计

按 TODO 要求，对每个 checkpoint 用**独立随机种子**（不复用训练用的 0~199，建议
200~299）跑 ≥100 次，分别统计四类失败：
- 右手夹取失败（`WAIT_RIGHT_GRASP` 阶段超时/`right_grasp_lost`）。
- 中央放置失败（`WAIT_CENTER_STABLE` 超时/倾倒/掉桌）。
- 左手再夹取失败（`WAIT_LEFT_GRASP` 阶段）。
- 蓝区放置失败（`WAIT_GOAL_STABLE` 未达 0.5 s 稳定）。

输出与 P4/P4.5 benchmark 一致的 CSV/JSON/PNG，外加**分阶段漏斗图**（每阶段通过率）。

## 5. 成功/失败视频与位置成功率分布

- 成功/失败各采样若干条导出 MP4（主视角 + 俯视 + 状态面板）。
- 绘制“终点 XY 误差分布 / 蓝区成功率热图 / 各 checkpoint 成功率曲线”，定位是哪
  个阶段、哪种几何条件失败最多，反过来指导数据增补或随机化调整。

## 6. 扰动测试

在评测里额外加三组扰动（与训练分布有 gap）：
- **光照**：`apply_visual_randomization` 之外再加大主光亮度/位置扰动。
- **相机**：外参平移和 fovy 超出训练范围。
- **物理**：纸杯质量/摩擦/指垫摩擦/夹持力取训练分布外的值，甚至加桌面高度微扰。

目的：验证策略不过拟合 P5 的窄分布，为 P8 sim2real 做准备。

## 7. 成功率目标

- **MVP**：≥80% 成功率（任意阶段失败都可接受，但能完整跑完多数 episode）。
- **稳定版**：≥90% 成功率，且分阶段失败均衡（没有某一阶段集中失败）。
- 对照：P4.5 脚本专家是 100%（开环最优上限），策略 90% 已可接受用于真机初探。

## 8. 验收（建议口径）

- LoRA 微调收敛，action 误差曲线下降并稳定。
- 最优 checkpoint 在 100 次独立种子闭环评测达 ≥80%（MVP）/ ≥90%（稳定版）。
- 分阶段失败统计 + 扰动结果落盘可复现。
