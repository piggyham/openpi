# P9：按真机 v0.3.0 格式重采 200 条数据

## 目标

重新采集 200 条双臂纸杯接力仿真演示，输出 OpenArm 数据集格式 v0.3.0，
与 `data/real_data/` 的目录结构和文件 schema 完全一致，可被厂商
`openarm_dataset` 工具链和本仓库 `real_data.py` 读取器直接消费。

## 输出格式

```
<dataset>/
├── metadata.yaml                     # version: '0.3.0', operation_type: scripted
└── episodes/<id>/                    # id = '0'..'199'
    ├── obs/arms/{left,right}/state.parquet
    │     timestamp: timestamp[ns]
    │     qpos/qvel/qtorque: list<element: float32> (8 元：7 关节 + gripper)
    ├── action/arms/{left,right}/qpos.parquet
    │     timestamp: timestamp[ns]
    │     value: list<element: float32> (8 元：关节目标 + gripper)
    └── cameras/{head,wrist_left,wrist_right}/<unix_ns>.jpeg
```

## 关键映射

| 仿真侧（npz） | v0.3.0 输出 |
|---|---|
| front / left_wrist / right_wrist（640×480 JPEG） | head / wrist_left / wrist_right（不解码重压） |
| state 7 关节 rad + 开度 m | 关节直通；gripper raw = opening/0.044 − 1 |
| qvel 7 关节 + 两指速度均值 | 直通 |
| qtorque = ctrl 力矩 + 两指力均值 | 直通 |
| joint_target 7 关节 rad + 目标开度 m | 关节直通；gripper raw = opening/0.044 − 1 |
| 仿真秒 + wall_start_ns | ns = wall_start_ns + round((t−t₀)·1e9) |
| 20 Hz 全流同步 | frequencies.cameras.*: 20.0 |

## 已知说明

- 脚本专家夹爪开度范围约 [0.031, 0.044] m（raw ≈ [−0.30, 0.01]），
  非全行程 [0, 0.044] m，因专家只需轻夹纸杯。
- 本数据集使用 20 Hz 统一频率（仿真控制帧率），非真机 100 Hz obs / 30 Hz 相机。
- gripper raw 未裁剪（允许微小越界，如 0.012 对应 0.5 mm 过开）。
