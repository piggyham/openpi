# P4.5 · 无 weld 纯摩擦抓取与 100 次评测

> 状态：✅ 已完成
> 作用：P3/P4 的抓取本质上是 MuJoCo weld（刚性强力约束），真实抓取不是这样。
> P4.5 用**软指垫 + 力限位位置阻抗 + 接触/滑移检测**实现一套**完全不激活 weld**
> 的纯摩擦抓取，并用独立配置跑 100 次物理评测。它不改变 P3/P4 场景与基准。

## 1. 这一步要做什么

1. 给官方双指加独立柔性高摩擦指垫，禁用原刚性指面碰撞。
2. 夹爪改为 8~12 N 随机力上限的位置阻抗控制。
3. 运行时禁止激活任何 cup weld（违例即失败关闭）。
4. 用双指接触 + 最小执行器夹持力 + 夹爪开度确认抓取。
5. 闭合后加静置保持、抬升保持、接触丢失与相对位姿滑移检测。
6. 多段笛卡尔接近、低加速度搬运、0.64 m 垂直安全后撤。
7. P4.5 专用桌面抬高 50 mm，满足左手中央侧壁抓取可达性。
8. 约 50 mm 低空张开、重力落桌、连续稳定判定。
9. 随机化纸杯位姿/质量/杯体摩擦/指垫摩擦/夹持力。
10. 100 次纯摩擦评测，成功率 ≥95%、weld 违规 0。

实现：`friction_task.py`（`FrictionRelayTask`，覆写门控/释放/滑移/失败）、
`friction_expert.py`（`FrictionScriptedExpert`，覆写接近/放置/释放/编排）、
`config.py` 的 `FrictionMissionConfig`/`FrictionTaskConfig`/`FrictionExpertConfig`、
`p45_benchmark.py`（评测面板）。

## 2. 独立配置：`FrictionMissionConfig`（`config.py:170`）

继承 `MissionConfig` 但改：
- `table_center=(0.50,0.0,0.29)` → 桌面上表面 `z=0.33 m`（原 0.28，抬高 50 mm）。
  原因：官方 OpenArm v1 在 `z=0.28` 桌面下，左手无法到达中央低位侧壁抓取位，
  抬高桌面等于标定工作台高度，作为 P4.5 专用边界（SPEC §13）。
- `soft_finger_pads=True` → `model.py:_add_soft_finger_pads` 生效。
- `finger_servo_kp=240.0`（原 100，更硬的位置阻抗）。
- `finger_force_limit_n=8.0`（运行时再随机到 8~12）。
- 杯体阻尼调高（`cup_linear_damping=0.035`、`cup_angular_damping=0.002`）。

`FrictionTaskConfig`（`config.py:182`）改阈值：抓取 TCP 偏移 `0.020`、
静置/抬升保持各 `0.30 s`、指垫滑移摩擦 `2.1~2.9`、夹持力 `8~12 N`、
最小指力 `0.8 N`、接触丢失宽限 `0.12 s`、滑移位置容差 `0.014`、角度 `18°`、
释放悬停 `0.050`、最大落桌高度 `0.065`。

`FrictionExpertConfig`（`config.py:200`）：`retreat_height=0.64`（垂直安全后撤）、
`closed_gripper_target=0.0`、接触稳定 `0.30 s`、抬升 `1.20 s`、搬运 `1.55 s`、
下降 `1.10 s`、放置稳定 `0.45 s`——整体比 P4 慢，低加速度搬运。

## 3. 软指垫：`_add_soft_finger_pads`（`model.py:312`）

对左右两手的内外指：
- 把官方 `openarm_{side}_{finger}_finger_collision` 的 `contype/conaffinity` 置 0
  → **关闭刚性指面碰撞**（mesh 仍保留视觉）。
- 加 `mission_{side}_{finger}_finger_pad` box（`36×3×24 mm` 半尺寸，绿色）：
  `condim=6`（椭圆摩擦锥，含扭转摩擦）、`friction=(2.5,0.08,0.02)`、
  `solref=(0.006,1.0)`、`solimp=(0.97,0.995,0.001)`、`margin=0.0005`。
- 指垫位置按 `finger_pad_center_*` + `y_sign` 区分内外指。
- 指垫摩擦在 episode 内由 task 随机化到 `2.1~2.9`。

## 4. 力限位位置阻抗

P4.5 夹爪仍是 position actuator，但：
- 构造时 `_apply_randomized_gripper_force`（`friction_expert.py:68`）对左右手调
  `controller.set_gripper_force_limit(side, force_n)`，把
  `actuator_forcerange` 设为 ±随机力（8~12 N）。
- 每次整局重置后再次随机化（`_reset_for_episode_attempt` 覆写）。
- `kp=240` 让位置阻抗较硬，但力上限受限，等效“位置目标 + 力限位”的阻抗抓取。

## 5. 抓取确认（无 weld）：`FrictionRelayTask.grasp_gate` / `try_attach`

`grasp_gate`（`friction_task.py:77`）在 P3 门控基础上**追加力条件**：
- 继承 P3 的接触数=2、夹爪开度、水平/竖直容差、直立。
- 额外要求 `min(finger_forces(side)) ≥ min_finger_force_n=0.8 N`（双侧都有夹持力）。
  `gripper_forces` 读 `data.actuator_force[finger_actuator_ids]`。

`try_attach`（`friction_task.py:89`）：
- 门控通过后**不激活 weld**，只转移状态到 `{side}_ATTACHED` 并记
  `friction_grasp_confirmed`。
- 若发现任一 weld 激活 → `fail("weld_used_in_friction_mode")`（硬违例）。
- 重置接触丢失计时器。

> 所以 P4.5 的“抓取确认”是**双侧软指垫接触 + 夹持力达标 + 夹爪闭合到位**，杯子
> 全程由重力和摩擦维持，weld 始终关闭。

## 6. 抬升后双段保持

`_approach_and_attach`（`friction_expert.py:99`）确认抓取后：
1. `_set_phase("{side} 静态夹持验证")`。
2. `_hold(static_grasp_hold_seconds=0.30)`：原地保持夹持力，确认双指接触与相对位姿
   稳定；若 task 失败则抛错进恢复。
3. 记 `friction_grasp_succeeded`。
4. `_lift_welded`（注意名字沿用，但实际无 weld）抬到桌面+0.20，再
   `_hold(lifted_grasp_hold_seconds=0.30)`，并校验阶段已转 `RIGHT/LEFT_LIFTED`。

## 7. 搬运与释放：低空张开 + 重力落桌

`_place_welded`（`friction_expert.py:207`）：
- 先用关节空间 `_move_joints` 搬到目标 XY 上方桌面+0.20（`transport_seconds=1.55`，低加速度）。
- 再用 `_move_tcp_linear`（多段笛卡尔直线，`segments=7`）下降到
  `桌面 + cup_half_height + release_hover_clearance(0.050)`，即杯底距桌面约 50 mm。
- `_hold(place_settle_seconds=0.45)` 停稳。

`_release_and_retreat`（`friction_expert.py:251`）：
1. `friction_task.prepare_release(side)` 校验：目标区域、直立、低速、高度上限、
   无 weld 激活——通过才允许释放。
2. 张开夹爪到 `gripper_open_position`，`_hold(0.45)` 让杯子**由重力+摩擦+桌面碰撞
   完成落桌**。
3. `_move_tcp` 到 `(retreat_xy, retreat_height=0.64)`（**先垂直后撤再回 home**，
   避免手指扫过交接区）。
4. `_move_joints` 回 home。

`_move_tcp_linear`（`friction_expert.py:75`）：在起点和终点间插 7 个 waypoint 逐步
`_move_tcp`，避免关节空间插值在杯口附近产生横向扫动。

## 8. 滑移与接触丢失检测：`update`（`friction_task.py:196`）

`FrictionRelayTask.update` 覆写 P3 的 `update`，对已附着阶段：
- 接触丢失宽限：双指接触数=2 且 `min(force) ≥ 0.35*0.8=0.28 N` 视为接触 OK；
  否则开始计时，超过 `contact_loss_grace_seconds=0.12 s` →
  `fail("{side}_contact_loss")`。
- 滑移检测 `_friction_slip`：算杯子相对 TCP 的当前 relpose 与抓取确认时记录的
  relpose 的偏差，位置 > `0.014` 或角度 > `18°` →
  `fail("{side}_friction_slip")`。
- 抬升判定同 P3（杯底过桌面+lift_clearance）。
- 仍检查 `weld_used_in_friction_mode`、掉桌、超时、非有限状态、过度倾倒。

## 9. 编排：`_run_success`（`friction_expert.py:289`）

纯摩擦任务初始化（随机化纸杯/指垫摩擦/夹持力）→ 右手力控夹取（软指垫双侧接触，
不启用 weld）→ 静态夹持验证 → 抬升 → 纯摩擦搬运至中央 → 释放后撤 → 确认
`WAIT_LEFT_GRASP` → 左手力控接力 → 搬运至蓝区 → 释放后撤 → 无约束成功判定
（蓝区、直立、桌面接触、双手退出、weld 始终关闭）。复用 P4 的整局重置层与碰撞监控。

## 12. 验收结果（SPEC §14）

- 种子 0~99 共 100 次，同时随机化 XY/yaw/质量/杯体摩擦/指垫摩擦/夹持力上限。
- **成功率 100/100，达 ≥95% 验收线**；weld 违规 0、意外碰撞 0、整局失败 0。
- 平均终点 XY 误差 `28.346 mm`，P95 `28.672 mm`，最大 `28.737 mm`。
- 平均最终倾角 `7.973°`，最大 `8.132°`。
- MuJoCo 2.3.7 与 3.2.3 均通过 25/25 项自动测试。

> P4.5 误差比 P4 大（weld 抓取几乎零误差），这是真实摩擦抓取的物理代价，但成功率
> 仍 100%，证明纯摩擦路线可行——也是 P5 采集数据所用的专家（真实抓取策略要学的
> 就是这种不带 weld 的行为）。
