# OpenArm v1 双臂纸杯接力 Todo List

任务目标：右臂从机器人右前方红色区域 A 夹起无把手一次性纸杯，直立放到
桌面中央；右臂退出后，左臂从中央夹起纸杯，再直立放到机器人左前方蓝色区域 B。
